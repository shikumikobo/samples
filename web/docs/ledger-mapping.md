# 台帳（スプレッドシート）との対応

GAS の見本（`samples/_shared/ledger.json`）の台帳と同じ形に寄せています。スプレッドシートの台帳から、このアプリへ移行できることを示す対応表です。

## このアプリで新しく持つもの（台帳にないもの）
- 役割と権限：`permissions`・`role_permissions`
- ファイル：`files`（現場ごと・共有先 `visibility`：社内のみ／お客さん／協力業者／両方）
- 外部への許可：`site_access`（現場ごと・ユーザーごと）
- 変更の履歴：`audit_log`（トリガーが書く）

## CSV で移行する手順（本番の Supabase の場合）
1. スプレッドシートの各シート（顧客・現場・見積・見積明細・担当者・予定）を、CSV でダウンロードする
2. 上の対応表のとおり列名を付け替える（例：`現場番号` → `id`、`契約金額` は `site_finance` の CSV に分ける）。状況・役割の値は同じ言葉のまま使える（役割だけ、営業・事務→`staff`、職人→`worker` に直す）
3. `db/schema.sql`・`functions.sql`・`permissions.sql`・`policies.sql`・`triggers.sql` を Supabase に流す
4. CSV を、顧客 → 担当者（`app_users`）→ 現場 → 金額 → 予定 → 見積 → 明細の順に取り込む（外部キーの順）
5. `site_access` で、お客さん・協力業者に見せる現場を許可する

※ この見本のデモでは、手順 4 は行わず、`db/seed.sql`（架空のデータ）を使います。
